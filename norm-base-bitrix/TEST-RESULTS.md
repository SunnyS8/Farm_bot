Python проверяет фактическую SQL-схему и SQL retrieval из `Consultant.php`: идемпотентность схемы, FK, включительные границы сроков, отсев непроверенного и пересечений. Это не исполнение PHP.

Node проверяет безопасные ID ссылок, сериализацию проверенных пунктов и статические контракты UI/защиты entrypoint. Статический тест не доказывает корректность серверной авторизации на конкретной сборке Bitrix.

На первом запуске тестов выявлено несовпадение API/frontend contracts и диагностический посторонний токен в API. Исправлены до повторного зелёного прогона. PHP runtime всё равно обязателен перед выкладкой.
